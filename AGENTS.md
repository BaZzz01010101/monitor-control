# Chat Rules

Never propose show in a web browser mockups, diagrams, comparisons, and other visuals!!!

## Testing Rules

- Do not add tests that inspect hand-written source files as text.
- Do not add tests that assert exact source contents, multiline source snippets, formatting, whitespace, or line endings.
- Prefer behavioral, state-based, API-level, or integration tests.
- Source-inspection tests are allowed only for generated artifacts or machine-readable outputs.
- If a source-inspection test for a hand-written file seems unavoidable, stop and ask first.
