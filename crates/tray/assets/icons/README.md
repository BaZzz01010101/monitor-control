# Tray Icons

These PNG icons are Bootstrap Icons renditions used by the native NWG tray UI.
They were downloaded from IconArchive's Bootstrap icon pack mirror for PNG
compatibility with NWG. Bootstrap Icons are licensed under MIT; see
`LICENSE.bootstrap-icons.txt`.

Downloaded icons:

- `arrow-clockwise` -> `refresh.png`
- `brightness-high` -> `brightness.png`
- `circle-half` -> `contrast.png`
- `displayport` -> `displayport.png`
- `hdmi` -> `hdmi.png`
- `pc-display-horizontal` -> `monitor.png`
- `thunderbolt` -> `thunderbolt.png`
